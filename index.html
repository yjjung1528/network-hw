    신뢰성을 보장하는 TCP와 빠른 전송을 위한 UDP의 차이점 분석

    네트워크 대역을 나누고 호스트를 식별하기 위한 서브넷팅 계산 방식
  • 4. HTTP 통신 과정
    웹 브라우저와 웹 서버 간의 요청(Request)과 응답(Response) 구조
